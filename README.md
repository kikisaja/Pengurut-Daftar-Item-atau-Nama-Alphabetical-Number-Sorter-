# Proyek 86: List & Name Sorter (Pengurut Daftar Item)

Proyek ini adalah aplikasi web praktis untuk mengurutkan daftar nama, baris teks, atau deret angka secara otomatis berdasarkan urutan alfabet (A-Z / Z-A), panjang karakter, maupun acak (*shuffle*). Sangat berguna untuk pengolahan data daftar siswa, inventaris, atau daftar entri teks. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, cocok sebagai modul pembelajaran algoritma pengurutan array (*array sorting*) bagi siswa SMK/pemula.
